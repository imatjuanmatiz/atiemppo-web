What the model does

It understands, searches, calculates and explains.

The model turns a natural-language message into a structured query against the SICETAC base and returns comparable values by route, configuration, logistics hours and tolls.

01 · MESSAGE

Understands the request

It reads messages such as “Cartagena to Bogotá C3S3”, “plus mode H8” or “toll detail”.

02 · ROUTE

Identifies the route

It normalizes origin and destination, searches matches and selects the main route when several options exist.

03 · CONFIGURATION

Applies the configuration

It uses the requested configuration or compares several when plus mode is selected.

04 · SCENARIOS

Calculates scenarios

It returns values by logistics hours and accepts an explicit hour when requested.

05 · TOLLS

Explains tolls

It includes total tolls and can open the detail by toll category and value.

Ways to query

A quick query or a full comparison.

The service recognizes routes written in normal language. When you have a clear route, it returns the SICETAC value; when you need comparison, plus mode opens the wider view.

Normal modeOne route and one configuration, with logistics hours and total tolls.
Plus modeAll available configurations for the same route, with total tolls by configuration.
Explicit hourRequest H8, h8 or 8 hours, with or without plus mode.
Public entryWhatsApp or the web query, using SICETAC reference conventions.

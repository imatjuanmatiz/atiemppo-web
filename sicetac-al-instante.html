Dos formas de consultar

El sistema reconoce rutas en texto normal. Cuando hay una ruta clara, devuelve el valor SICETAC; cuando necesitas comparar, el modo plus abre el panorama completo.

Modo normal

Sirve para una ruta y una configuración específica. Entrega los valores por horas logísticas y el total de peajes de esa configuración.

Ejemplo: Cartagena a Bogota C2S3

Modo plus

Sirve para comparar todas las configuraciones disponibles de una misma ruta. Por defecto responde con H4 y muestra el peaje total por configuración.

Ejemplo: Cartagena a Bogota, modo plus

Hora explicita

Puedes pedir una hora logística concreta con o sin modo plus. El sistema prueba la hora solicitada cuando está disponible en el cálculo.

Ejemplos: H8, h8, 8 horas, modo plus H6

La respuesta rápida no solo muestra el valor SICETAC. También deja visible cuánto corresponde a peajes para que el equipo comercial u operativo tenga contexto inmediato.

Detalle de peajes

Después de consultar una ruta, puedes pedir el detalle y el sistema recuerda la última ruta. Si vienes de modo plus, puedes pedir una configuración puntual.
